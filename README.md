# site-safety-detector

a browser extension that warns you about potentially unsafe websites using community-sourced data.

## what is this?

a browser extension that warns you about potentially unsafe websites using community-sourced data.

this is a fork of [fmhy/FMHY-SafeGuard](https://github.com/fmhy/FMHY-SafeGuard) with a redesigned ui.

## original vs. this version

### changes from original

- redesigned the ui with a dark pkm aesthetic. all text is now lowercase. extension renamed from fmhy-safe-guard to site-safety-detector. auto-update checking added.

## installation

download the `.xpi` file from releases and open it in firefox, or load it temporarily via `about:debugging` > this firefox > load temporary add-on.
